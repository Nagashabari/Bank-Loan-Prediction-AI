ABOUT THE PROJECT

Bank Loan Prediction AI is a decision-support project.

An end-to-end AIML web application combining an existing loan approval classifier with financial analysis, explainability, visualization and user workflows.

What is ML vs what is calculated?

ML-powered: approval probability and model feature importance.

Calculated: EMI, DTI, affordability and repayment metrics.

Estimated: recommended loan amount, indicative rate and credit-score-style indicator. These are transparent project estimates, not bank underwriting decisions.
